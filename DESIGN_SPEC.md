# DESIGN_SPEC.md

## Overview
The `sinhala-english-tutor` has evolved into **TalkMate** — a real-time, bilingual (Sinhala and English) spoken English AI companion. It is designed for Sri Lankans who comprehend English but lack conversational practice. 

Unlike standard tutor bots, TalkMate operates as a **friend**, completely avoiding traditional educational vocabulary (e.g., "teacher", "lesson", "student"). It intercepts native 1-on-1 Telegram phone calls (via `pyrogram` and `pytgcalls`), manages learning state via Google ADK, and bridges live WebRTC audio directly to the `gemini-2.5-flash-native-audio` model for seamless, low-latency conversation.

## Core Capabilities & Learning Cycles
1. **Iterative Onboarding:** Instead of a static assessment, the agent builds a dynamic user profile (Name, Age, Gender, Role, Interests) naturally over the first few conversation turns.
2. **Contextual Persona Adaptation:** The agent is culturally aware and dynamically weaves in Sri Lankan context (e.g., Colombo traffic, kottu) while matching the user's demographic.
3. **Instant-Pause Grammar Correction:** The agent acts as a supportive friend who gently interrupts, corrects spoken grammar in real-time, explains the rule briefly, and logs the mistake.
4. **Persistent Episodic Memory:** A custom `UserStore` database extracts and saves relevance-weighted personal facts about the user across multiple calls, enabling organic catch-ups.
5. **Spaced Repetition System (SRS):** Grammar mistakes are logged as `LearningTarget`s. The agent tracks mastery levels and naturally weaves due targets into future conversations to test the user's progress.
6. **Automated Post-Call Summaries:** When the user hangs up, a dynamic Telegram message is generated by `gemini-2.5-flash` summarizing the exact mistakes made and their correct forms.

## Architecture & Integration Strategy
- **Telegram Client:** `Pyrogram` logs into a dedicated "burner" Telegram account.
- **Audio Routing:** `pytgcalls` intercepts incoming 1-on-1 calls. `FFmpeg` handles transcoding (48kHz to 16kHz and vice versa).
- **Audio Bridge:** A custom asynchronous TCP bridge (`bridge/audio_bridge.py`) pipes raw PCM audio between FFmpeg and the Gemini Live WebSocket. 
- **Agent Logic:** Google ADK handles the `root_agent`, prompt instructions, tool routing, and skill delegation.
- **State Persistence:** A custom SQLite/SQLAlchemy database (`core/user_store.py`) replaces the basic ADK memory, providing structured tracking for `User`, `UserMemory`, and `LearningTarget`.

## Skill Architecture
The agent is divided into focused ADK skills:
- **`onboarding-skill`:** Gathers user profile data naturally.
- **`catch-up-skill`:** Uses episodic memory to re-engage returning users organically.
- **`adaptive-conversation-skill`:** Manages the main flow of the conversation.
- **`grammar-correction-skill`:** Governs the `instant_pause` correction mechanics and language ratio.
- **`dynamic-memory-skill`:** Silently runs in the background to extract and save facts.

## Essential Tools
- **`update_user_profile`:** Called only when the user explicitly provides profile data.
- **`extract_and_save_memory`:** Silently saves atomic facts about the user for future recall.
- **`log_learning_target`:** Called immediately after correcting a user to save the mistake for the SRS.
- **`update_learning_progress`:** Called after the agent naturally tests a due learning target.
- **`change_correction_style`:** Adjusts user preferences between `recast_only` and `instant_pause`.
- **`Google Search`:** Built-in ADK tool for real-world factual lookups.

## Constraints & Safety Rules
- **Anti-Tutor Constraint:** The agent must NEVER use words like "teacher", "tutor", "coach", "lesson", "student". It must always act as a "friend" or "buddy".
- **Telegram TOS Constraint:** The application MUST run on a dedicated/burner phone number.
- **Audio Format Match:** Audio streams MUST be explicitly transcoded to 16kHz raw PCM for Gemini and 48kHz for Telegram.
- **Anti-Hallucination:** The agent must NEVER invent user data, make up past conversations, or hallucinate mistakes in the post-call summary.

## Edge Cases to Handle
- **Dropped Calls:** If the user hangs up abruptly, `pytgcalls` must catch the event, gracefully close the bridge, save the ADK session state, and trigger the text-based LLM post-call summary.
- **Silence/Background Noise:** The agent must gracefully handle periods of silence without hallucinating responses. 
- **Pure Sinhala Input:** The agent must comfort panicked users in fluent Sinhala and gently guide them back to English, adjusted to their tracked level.

## Success Criteria
- The Userbot answers incoming 1-on-1 Telegram calls automatically.
- The TCP audio bridge operates with sub-2-second latency and clear audio quality.
- The `UserStore` successfully persists episodic memories and SRS targets across different calls.
- The agent naturally recalls a past memory when a user calls back.
- A personalized Telegram text summary containing the specific grammar mistakes made during the call is successfully generated and delivered upon hang-up.
